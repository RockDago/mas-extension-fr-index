## Utilisation - Usage

Les extensions peuvent être téléchargées, installées et désinstallées depuis l'application Aniyomi ou AnymeX.
Elles sont installées et désinstallées comme des applications classiques au format `.apk`.

Extension sources can be downloaded, installed, and uninstalled via Aniyomi or AnymeX.
They are installed and uninstalled like regular apps in `.apk` format.

### Téléchargements - Downloads

Si tu préfères télécharger directement les fichiers APK, ils sont disponibles dans ce dépot sur la [branche `repo`](https://github.com/RockDago/mas-extension-fr-index/tree/repo/apk).

If you prefer to directly download the APK files, they are available directly in this repository in the
[`repo` branch](https://github.com/RockDago/mas-extension-fr-index/tree/repo/apk).

## Demandes - Issues

Les demandes d'extensions sont laissées au bon vouloir des développeurs, il est donc impossible de donner un délai de développement.  
De plus, certaines sources sont simplement impossibles à implémenter à cause de diverses raisons techniques.

Source requests here are meant as up-for-grabs for any developer, thus it's impossible to provide a time estimation for any of them.  
Check out the repo's [issue backlog](https://github.com/RockDago/mas-extension-fr-index/issues) for source requests and bug reports.    
Pour te lancer dans le développement, lis [CONTRIBUTING.md](./CONTRIBUTING.md).  
C'est aussi une bonne idée de lire le [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).

Contributions are welcome!  
Check out the repo's [issue backlog](https://codeberg.org/hollow/aniyomi-extensions-fr/issues) for source requests and bug reports.  
To get started with development, see [CONTRIBUTING.md](./CONTRIBUTING.md).  
It might also be good to read our [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).
